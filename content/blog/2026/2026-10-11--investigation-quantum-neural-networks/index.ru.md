## <span class="section-num">2</span> Темы работ {#темы-работ}


### <span class="section-num">2.1</span> Физика и химия {#физика-и-химия}

-   Моделирование динамики квантовых систем с помощью квантовых нейронных сетей
    -   Объект: эволюция спиновых цепочек, двухуровневых систем.
    -   Метод: QNN, обучение на данных точной диагонализации.

-   Квантовая нейронная сеть для аппроксимации решений уравнения Шрёдингера
    -   Объект: волновые функции, потенциалы.
    -   Метод: вариационные квантовые схемы, гибридное обучение.

-   Применение QNN для моделирования молекулярных спектров и энергий связи
    -   Объект: малые молекулы (H₂, LiH).
    -   Метод: QNN + VQE-подход, сравнение с классическими моделями.

-   Моделирование нелинейных осцилляторов с помощью аппаратно-эффективных квантовых схем
    -   Объект: уравнение Дуффинга, маятник.
    -   Метод: HEA, угловое кодирование, регрессия.

-   Квантовые нейронные сети для решения обратных задач в физике
    -   Объект: восстановление параметров системы по наблюдениям.
    -   Метод: QNN-регрессия, шумовые каналы.


### <span class="section-num">2.2</span> Биология, экология, медицина {#биология-экология-медицина}

-   Построение квантовой нейронной сети для моделирования популяционной динамики системы трёх трофических уровней
    -   Объект: модель Лотки--Вольтерры (хищник--жертва).
    -   Метод: HEA, сеточный поиск гиперпараметров.

-   Гибридная квантово-классическая нейронная сеть для моделирования эпидемии SIR
    -   Объект: распространение инфекции.
    -   Метод: QNN + классический оптимизатор, сравнение с ODE-решением.

-   Квантовая нейронная сеть для прогнозирования динамики нейронной активности
    -   Объект: временные ряды ЭЭГ/фМРТ.
    -   Метод: QRNN, угловое кодирование, регрессия.

-   Моделирование динамики сердечного ритма с использованием вариационных квантовых схем
    -   Объект: кардиограммы.
    -   Метод: QNN-классификация аномалий, гибридное обучение.

-   Применение QNN для моделирования роста опухоли и иммунного ответа
    -   Объект: системы дифференциальных уравнений.
    -   Метод: QNN-аппроксимация, сравнение с классическими сетями.


### <span class="section-num">2.3</span> Экономика и финансы {#экономика-и-финансы}

-   Квантовая нейронная сеть для прогнозирования финансовых временных рядов
    -   Объект: цены акций, валютные курсы.
    -   Метод: QNN с LSTM-подобной архитектурой, гибридное обучение.

-   Моделирование волатильности финансовых рынков с помощью квантовых ядерных методов
    -   Объект: модель GARCH, опционы.
    -   Метод: quantum kernel, регрессия.

-   Гибридные квантово-классические модели для прогнозирования энергопотребления
    -   Объект: временные ряды нагрузки.
    -   Метод: QNN + классический preprocessing, оценка MSE.


### <span class="section-num">2.4</span> Инженерия и технические системы {#инженерия-и-технические-системы}

-   Квантовая нейронная сеть для моделирования турбулентности
    -   Объект: уравнения Навье--Стокса.
    -   Метод: QNN-аппроксимация полей скорости.

-   Моделирование динамики робототехнических систем с использованием QNN
    -   Объект: манипулятор, мобильный робот.
    -   Метод: QNN-регрессия, обучение с подкреплением.

-   Квантовые нейронные сети для обнаружения аномалий во временных рядах
    -   Объект: телеметрия, сенсоры.
    -   Метод: автоэнкодер на VQC, классификация.

-   Применение QNN для моделирования климатических данных
    -   Объект: температура, осадки.
    -   Метод: QNN-прогноз, сравнение с классическими моделями.


### <span class="section-num">2.5</span> Методология и алгоритмы QNN {#методология-и-алгоритмы-qnn}

-   Сравнение стратегий кодирования данных в квантовых нейронных сетях для задач моделирования
    -   Объект: угловое, амплитудное, базисное кодирование.
    -   Метод: экспериментальное сравнение на регрессии.

-   Исследование влияния шума на обучение QNN для моделирования динамических систем
    -   Объект: деполяризующий шум, канал Паули.
    -   Метод: симуляция шумных устройств, оценка устойчивости.

-   Байесовская оптимизация архитектуры квантовой нейронной сети для моделирования
    -   Объект: число кубитов, слоёв.
    -   Метод: Gaussian Process, сравнение с grid search.

-   Применение QSVT для нелинейных преобразований в квантовых нейронных сетях
    -   Объект: блоковое кодирование, матричные функции.
    -   Метод: QSVT + QNN, моделирование.

-   Квантовые сверточные нейронные сети для анализа и прогнозирования временных рядов
    -   Объект: многомерные сигналы.
    -   Метод: QCNN, сравнение с классической CNN.

-   Гибридные квантово-классические рекуррентные сети для моделирования последовательностей
    -   Объект: динамические системы. _Метод:_ QRNN, обучение через backpropagation.

-   Сравнение квантовых и классических нейронных сетей в задаче аппроксимации хаотических систем
    -   Объект: аттрактор Лоренца, логистическое отображение.
    -   Метод: QNN vs MLP, оценка точности и сложности.


### <span class="section-num">2.6</span> Разное {#разное}

-   Моделирование квантовых систем с помощью квантовых нейронных сетей (quantum learning of quantum dynamics)

    -   Объект: вероятностные распределения.
    -   Метод: Quantum GAN, обучение на данных.

-   Квантовые нейронные сети для моделирования многомасштабных процессов
    -   Объект: мультифизические задачи.
    -   Метод: гибридные схемы, multi-scale QNN.

-   Разработка библиотеки на Python для обучения QNN в задачах моделирования

    -   Объект: астрономические, микроскопические снимки. _Метод:_ QCNN, transfer learning.
