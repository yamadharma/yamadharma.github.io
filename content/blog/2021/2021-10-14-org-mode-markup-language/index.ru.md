## <span class="section-num">1</span> Внешний вид {#внешний-вид}


### <span class="section-num">1.1</span> Изображения {#изображения}

-   Изображение можно вставлять просто в виде имени файла:
    ```org
    ./img/cat.jpg
    ```
-   Можно задать заголовок и метку для изображения. Тогда изображение вставляется в виде ссылки.
    ```org
    #+CAPTION: Заголовок изображения
    #+NAME:   fig:image-a
    [[./img/a.jpg]]
    ```
-   Такие изображения можно отобразить в буфере с помощью команды: `C-c C-x C-v` (`org-toggle-inline-images`).
-   При вызове с префиксом также отображать изображения, у которых есть заголовок: `C-u C-c C-x C-v`.
-   Можно активировать отображение встроенных изображений при запуске:
    -   настроив переменную `org-startup-with-inline-images`;
    -   установив в буфере параметр `STARTUP` в `inlineimages` (или `noinlineimages`).

## <span class="section-num">2</span> Заголовки разделов {#заголовки-разделов}

```org
* Самый большой заголовок (уровень 1)

Новая глава.

** Больший заголовок (уровень 2)

Новый раздел.

*** Большой заголовок (уровень 3)

Новый подраздел.

**** Заголовок (уровень 4)

Новый подподраздел.
```

-   Можно создавать нумерованные заголовки до определенного уровня, задав параметр:

<!--listend-->

```org
#+OPTIONS: H:4
```


## <span class="section-num">3</span> Абзацы {#абзацы}


### <span class="section-num">3.1</span> Обычные {#обычные}

```org
Один перевод строки не имеет эффекта.
Эта строка является частью того же абзаца.

Пустая строка

разграничивает абзацы.
```


### <span class="section-num">3.2</span> Горизонтальные линии {#горизонтальные-линии}

-   Для горизонтальной линии вставьте не менее 5 тире.
    ```org
    Текст над горизонтальной линией.
    -----
    Текст под горизонтальной линией.
    ```


## <span class="section-num">4</span> Форматирование текста {#форматирование-текста}


### <span class="section-num">4.1</span> Полужирный и курсив {#полужирный-и-курсив}

-   Выделение текста.
    ```org
    /Emphasize/ (курсив), *strongly* (жирный) и */very strongly/* (жирный курсив).
    ```

-   Элементы разметки могут быть вложенными:
    ```org
    Это /курсивный текст, содержащий _подчёркнутый текст_ внутри себя/, тогда как _это обычный подчёркнутый текст_.
    ```

-   Разметка может занимать несколько строк, по умолчанию не более 2:

<!--listend-->

```org
*Это
не
жирный шрифт.*
```

-   Режим Org не интерпретирует маркер, окруженный буквенно-цифровыми символами, как маркер выделения.
-   Поэтому нельзя выделить только часть слова.


### <span class="section-num">4.2</span> Моноширинный, верхний и нижний индексы. {#моноширинный-верхний-и-нижний-индексы-dot}

```org
- моноширинный шрифт пишущей машинки для ~встроенного кода~
- моноширинный шрифт пишущей машинки для =дословного текста=
- +удаленный текст+ (в отличие от _вставленного текста_)
- текст с верхним индексом, например, 2^{10}
- текст с нижним индексом, например, H_{2}O
```


## <span class="section-num">5</span> Списки {#списки}

-   Разметка Org позволяет создавать маркированные или нумерованные списки.
-   Допускается любая комбинация типов списков.


### <span class="section-num">5.1</span> Неупорядоченные списки {#неупорядоченные-списки}

-   Списки с пунктами помечаются маркерами.
-   Создавайте их с помощью знака минус или плюс.
    ```org
    ​- Пункт с длинным текстом, переносящимся, желательно, на несколько строк. Добавлено несколько слов, чтобы наглядно показать перенос строк.
    ​- Маркер.
    ​  + Маркер.
    ​    * Маркер.
    ```


### <span class="section-num">5.2</span> Контрольные списки {#контрольные-списки}

-   Отмечется с помощью `C-c C-c`.

<!--listend-->

```org
- [X] Отмечено.
- [-] Отмечено наполовину.
- [ ] Не отмечено.
- Обычный пункт списка.
```


### <span class="section-num">5.3</span> Упорядоченные списки {#упорядоченные-списки}

-   Нумерованные списки помечаются цифрами или буквами:

<!--listend-->

```org
1. Элемент списка с арабской (десятичной) нумерацией.
   A. Элемент списка с номером, начинающимся с заглавной буквы.
      a. Строчная буква.
      b. Строчная буква.
   B. Заглавная буква.
2. Номер.
```

-   Можно иметь упорядоченные списки с заданием номера:
    ```org
    2. [@2] Начинаем с пункта номер 2.
    3. Элемент с автоматической нумерацией.
    ```


### <span class="section-num">5.4</span> Списки определений {#списки-определений}

-   Помеченные многострочные списки.
    ```org
    ​- Первый термин для определения ::
         Определение первого термина. Добавляем несколько слов, чтобы показать перенос строк, чтобы увидеть, что происходит при длинных строках.

    - Второй термин ::
         Объяснение второго термина с помощью *встроенной разметки*.

         Во многих абзацах.
    ```


### <span class="section-num">5.5</span> Разделение списков {#разделение-списков}

-   Смежные списки иногда сливаются.
-   Чтобы начать новый список, сместите два списка на пустую строку комментария:
    ```org
    ​- apples
    ​- oranges
    ​- bananas

    # Комментарий.

    - carrots
    ​- tomatoes
    ​- celery
    ```


## <span class="section-num">6</span> Таблицы {#таблицы}

-   Таблицы легко создавать и читать.


### <span class="section-num">6.1</span> Простая таблица {#простая-таблица}

-   В таблицах Org ячейки имеют длину не более одной строки.
-   В Org не существует многострочных ячеек таблиц.
    ```org
    | Ячейка в столбце 1, строка 1 | Ячейка в столбце 2, строка 1 |
    | Ячейка в столбце 1, строка 2 | Ячейка в столбце 2, строка 2 |
    ```


### <span class="section-num">6.2</span> Форматирование столбцов {#форматирование-столбцов}

-   Столбцы выравниваются автоматически:
    -   числовые столбцы --- справа;
    -   строковые столбцы --- слева.


#### <span class="section-num">6.2.1</span> Таблица с выровненными ячейками {#таблица-с-выровненными-ячейками}

-   Чтобы изменить автоматическое выравнивание, используйте `<r>`, `<c>` или `<l>`.
    ```org
    #+caption: Таблица с выровненными столбцами
    |          <r> |     <c>      | <l>          |
    |            1 |      2       | 3            |
    |       Справа |  По центру   | Слева        |
    | xxxxxxxxxxxx | xxxxxxxxxxxx | xxxxxxxxxxxx |
    ```


### <span class="section-num">6.3</span> Строка заголовка {#строка-заголовка}

-   Можно создать таблицу со строкой заголовка
-   Используем горизонтальную линию тире для отделения ее от остальной части таблицы.
    ```org
    #+caption: Таблица с заголовком
    | Название столбца 1 | Название столбца 2   | Название столбца 3 |
    |--------------------+----------------------+--------------------|
    | Верхний левый угол | Верхний средний угол |                    |
    |                    |                      | Справа             |
    | Нижний левый угол  | Нижний средний угол  |                    |
    ```


### <span class="section-num">6.4</span> Размещение таблицы {#размещение-таблицы}

```org
#+ATTR_LATEX: :center nil
| a | b |
| 1 | 2 |
```

XXX Отличается от следующего:

```org
| a | b |
| 1 | 2 |
```


### <span class="section-num">6.5</span> Выравнивание таблиц по странице {#выравнивание-таблиц-по-странице}

-   Выравнивание при экспорте в LaTeX.


#### <span class="section-num">6.5.1</span> По левому краю {#по-левому-краю}

-   Параметр `noindent` просто убирает отступ первой строки абзаца, которая в данном случае является таблицей.
-   Параметр `hfill` добавляет бесконечное растяжение после таблицы, поэтому он сдвигает таблицу влево.
    ```org
    #+LATEX: \noindent
    #+ATTR_LATEX: :center nil
    | a | b | c |
    |---+---+---|
    | 1 | 2 | 3 |
    | 4 | 5 | 6 |
    #+LATEX: \hfill
    ```


#### <span class="section-num">6.5.2</span> По центру {#по-центру}

```org
| a | b | c |
|---+---+---|
| 1 | 2 | 3 |
| 4 | 5 | 6 |
```


#### <span class="section-num">6.5.3</span> Справа {#справа}

-   `hfill` добавляет бесконечное растяжение перед таблицей, поэтому она сдвигает таблицу вправо.

<!--listend-->

```org
#+LATEX: \hfill
#+ATTR_LATEX: :center nil
| a | b | c |
|---+---+---|
| 1 | 2 | 3 |
| 4 | 5 | 6 |
```


### <span class="section-num">6.6</span> Размер таблицы {#размер-таблицы}

```org
#+ATTR_HTML: :width 100%
#+ATTR_LATEX: :width 100%
| Ячейка в столбце 1, строка 1 | Ячейка в столбце 2, строка 1 |
| Ячейка в столбце 1, строка 2 | Ячейка в столбце 2, строка 2 |
```

## <span class="section-num">10</span> Цитирование {#цитирование}


### <span class="section-num">10.1</span> Цитата {#цитата}

-   Блок `quote` для контента, не требующего сохранения переносов строк.

<!--listend-->

```org
#+begin_quote
Давайте изменим наше традиционное отношение к построению программ:
вместо того, чтобы представлять, что наша главная задача --- инструктировать компьютер, что делать,
давайте сосредоточимся на объяснении людям, что мы хотим,
чтобы компьютер делал.

Практикующего грамотное программирование можно рассматривать как эссеиста, чья
главная забота --- изложение и совершенство стиля. Такой автор, имея
под рукой тезаурус, тщательно выбирает имена переменных и объясняет, что
означает каждая переменная. Он или она стремится к программе, которая понятна,
потому что ее концепции введены в порядке, наиболее подходящем для человеческого
понимания, используя сочетание формальных и неформальных методов, которые усиливают
друг друга.

-- Дональд Кнут
, #+end_quote
```

```org
, #+begin_quote
Всё должно быть максимально простым,
но не проще. -- Альберт Эйнштейн
, #+end_quote
```


### <span class="section-num">10.2</span> Стих {#стих}

-   Блок `verse` в конце каждой строки неявно делается перенос строки, а отступ сохраняется:
    ```org
     #+begin_verse
    Всё должно быть максимально простым,
    но не проще. -- Альберт Эйнштейн
     #+end_verse
    ```

-   Обычно используется для цитирования отрывков из электронного письма:

<!--listend-->

```org
 #+begin_verse
>> Встреча перенесена на следующую пятницу.
>
> Перенесен ли также срок сдачи отчета?

Да. И проверьте http://www.doodle.com/ для переноса встречи.

В основном тексте
   отступы
сохраняются.
#+end_verse
```


## <span class="section-num">11</span> Комментарии {#комментарии}

-   Можно добавлять комментарии в документ.
    ```org
    # Этот комментарий Org здесь отображаться не будет.
    ```

-   Org не поддерживает комментарии внутри абзацев, поскольку комментарий завершает абзац.
-   Однако вы можете имитировать встроенные комментарии с помощью фрагментов экспорта, например, `@@comment:...@@`.

-   Если у вас есть таблицы, которые вы хотите игнорировать при экспорте, один из вариантов --- использовать блоки комментариев или поддеревья `:noexport:`.

## <span class="section-num">13</span> Исходный код {#исходный-код}


### <span class="section-num">13.1</span> Встроенный код {#встроенный-код}

```org
Справочный код, например, ~variables~ или ~functions~ inline.
```


### <span class="section-num">13.2</span> Блоки кода {#блоки-кода}

-   Блоки исходного кода поддерживают подсветку синтаксиса:

<!--listend-->

```cpp
/*
 * Приложение, которое выводит сообщение "Hello" в стандартный вывод.
 */
int main(int arc, char **argv)
{
  printf("Hello, %s!\n", (argc>1) ? argv[1] : "World");
  return 0;
}
```

```emacs-lisp
(defvar hello "Hello")

(defun hello (name &optional greeting)
  (message "%s %s" (or greeting "Hello") name))

(setq tab-width 4)
```


### <span class="section-num">13.3</span> Номера строк {#номера-строк}

-   Как в `example`, так и в `src` в фрагментах кода можно добавить оператор `-n` в конец строки `begin`, чтобы получить нумерацию строк:

<!--listend-->

```text
#+begin_src emacs-lisp -n
(defun org-xor (ab)
  "Исключающее ИЛИ."
#+end_src
```

```emacs-lisp { linenos=true, linenostart=1 }
(defun org-xor (ab)
  "Исключающее ИЛИ."
```

-   При использовании оператора `+n` нумерация из предыдущего пронумерованного фрагмента будет продолжена в текущем:

<!--listend-->

```text
#+begin_src emacs-lisp +n
  (if a (not b) b))
#+end_src
```

```emacs-lisp { linenos=true, linenostart=3 }
(if a (not b) b))
```


### <span class="section-num">13.4</span> Выноски {#выноски}

-   В HTML при наведении курсора мыши на такую ​​ссылку будет удаленно подсвечиваться соответствующая строка кода.

-   С ключом `-n` ссылки на эти ссылки будут помечены номерами строк из листинга кода, в противном случае ссылки будут использовать метки без скобок.

## <span class="section-num">14</span> Математика {#математика}

-   Можно встраивать математическое форматирование LaTeX в файлы Org mode.


### <span class="section-num">14.1</span> Строчные математические выражения {#строчные-математические-выражения}

-   Для встроенных математических выражений используйте обозначение в скобках `\(...\)`.
-   Использовать конструкцию `$...$` не рекомендуется.
    ```org
    Формула \(a^2 + b^2 = c^2\) была открыта Пифагором.

    Пусть \(a=\sin(x) + \cos(x)\). Тогда \(a^2 = 2\sin(x)\cos(x)\), потому что \(\sin^2x + \cos^2x = 1\).
    ```

### <span class="section-num">14.2</span> Выключные математические выражения {#выключные-математические-выражения}

-   Для математических выражений, которые вы хотите выделить, центрировав на отдельной строке, используйте `\[...\]`.
-   Двойные знаки доллара (`$$`) использовать не следует.
    ```org

    \[ \frac{-b \pm \sqrt{b^2 - 4 ac}}{2a} \]
    ```

### <span class="section-num">14.3</span> Номера уравнений {#номера-уравнений}

-   К выключному уравнению можно добавить метку и ссылаться на уравнение по имени (метке) в других частях текста.

## <span class="section-num">15</span> Подключение файлов {#подключение-файлов}


### <span class="section-num">15.1</span> Включение файлов Org {#включение-файлов-org}

-   Можно включить другой файл Org и пропустить его заголовок, используя аргумент `:lines` для `#+INCLUDE`:
