## <span class="section-num">1</span> План исследования {#план-исследования}


### <span class="section-num">1.1</span> Введение {#введение}

-   Актуальность темы
    -   Рост социальных сетей и анонимных сетей (Tor, I2P) как среды для распространения дезинформации, координации ботов и незаконной деятельности. Необходимость автоматизированных методов анализа на основе графов.
-   Объект и предмет исследования
    -   Объект --- социальные сети и даркнет-платформы.
    -   Предмет --- графовые модели и методы анализа структур связей для выявления ботов, дезинформации и ключевых узлов в даркнете.
-   Цель и задачи исследования
    -   Формулировка цели (например, разработка и сравнительная оценка графовых методов для нескольких задач).
    -   Конкретных задач (обзор, выбор архитектур, эксперименты, оценка).
-   Методы исследования
    -   Теория графов, графовые нейронные сети (GNN), алгоритмы поиска сообществ, анализ центральностей.
-   Научная новизна и практическая значимость
    -   Адаптация GNN к мультиреляционным графам.
    -   Сравнение методов на единых метриках.
    -   Выявление ограничений.


### <span class="section-num">1.2</span> Глава 1. Теоретические основы и обзор литературы {#глава-1-dot-теоретические-основы-и-обзор-литературы}

-   Базовые понятия теории графов и анализ социальных сетей.
    -   Степень вершины, центральности (degree, betweenness, closeness), модульность, алгоритмы поиска сообществ (Louvain, Leiden).
-   Графовые нейронные сети: архитектуры и применение.
    -   GCN, GraphSAGE, GAT, GIN. Механизмы message passing и neighborhood aggregation.
    -   Обзор результатов применения GNN в анализе социальных сетей.
-   Обзор методов
    -   Выявление ботов.
        -   Эволюция подходов: от признаковых моделей к графовым и мультимодальным.
        -   Групповой уровень детектирования через анализ подграфов и аномалий топологии.
    -   Обнаружение дезинформации
        -   Модели распространения новостей как графы.
        -   GNN и гибридные архитектуры (BERT + GNN, LLM + GNN).
        -   Характерные паттерны: высокая скорость распространения через влиятельные узлы, кластеры низкодостоверных пользователей.
    -   Анализ Darknet
        -   Исследование скрытых сервисов Tor и I2P как единой экосистемы.
        -   Выявление ключевых узлов и сообществ через метрики центральности. Визуализация и картирование экосистемы даркнета.
-   Выводы по главе
    -   Формулировка исследовательского пробела: необходимость систематического сравнения графовых методов на унифицированных наборах данных для трёх рассмотренных задач.


### <span class="section-num">1.3</span> Глава 2. Методология исследования {#глава-2-dot-методология-исследования}

-   Общая схема экспериментального исследования.
    -   Пайплайн: сбор/выбор данных → построение графов → обучение моделей → оценка метрик.
-   Наборы данных.
    -   Для ботов: MGTAB, TwiBot-22.
    -   Для дезинформации: FakeNewsNet.
    -   Для Darknet: датасет Interconnection between darknets.
-   Построение графов.
    -   Граф связей аккаунтов для задачи ботов.
        -   Узлы --- пользователи, рёбра --- взаимодействия (репосты, ответы, упоминания).
        -   Мультиреляционные рёбра.
    -   Граф распространения новости для задачи дезинформации.
        -   Узлы --- пользователи/посты, рёбра --- репосты, ответы, временные метки.
    -   Граф скрытых сервисов для задачи Darknet.
        -   Узлы --- домены `.onion` и `.i2p`, рёбра --- гиперссылки, общие технологии.
-   Выбор и обоснование моделей.
    -   Базовые модели:
        -   GCN, GraphSAGE, GAT.
    -   Специализированные:
        -   MultiBotGNN (для мультиреляционных графов ботов).
        -   Dual-Stream Graph-Augmented Transformer (BERT + GAT/Graph Transformer) для дезинформации.
    -   Для Darknet:
        -   алгоритмы центральности (in-degree, betweenness) и Leiden для поиска сообществ.
-   Метрики оценки.
    -   Accuracy, Precision, Recall, F1-score, AUC-ROC для задач классификации; модульность и conductance для анализа сообществ; устойчивость центральностей для Darknet.


### <span class="section-num">1.4</span> Глава 3. Экспериментальная часть {#глава-3-dot-экспериментальная-часть}

-   Эксперименты по выявлению ботов.
    -   Обучение GNN на MGTAB и TwiBot-22. Сравнение с признаковыми baseline-моделями.
    -   Анализ вклада различных типов рёбер (мультиреляционность) в качество детекции.
    -   Оценка устойчивости к маскировке ботов под реальных пользователей.
-   Эксперименты по обнаружению дезинформации.
    -   Обучение Dual-Stream модели (BERT + GNN) на PHEME/FakeNewsNet.
    -   Раннее обнаружение: оценка качества на временных срезах каскада (ранние стадии распространения).
    -   Визуализация графов распространения: сравнение паттернов фейковых и реальных новостей.
-   Эксперименты по анализу Darknet.
    -   Построение графа сервисов. Вычисление метрик центральности. Выявление топ-узлов по in-degree.
    -   Применение алгоритма Leiden для выделения сообществ по типам активности (хакерство, финансы, крипто).
    -   Анализ связей между Tor и I2P: поиск мостовых сервисов.
-   Сравнительный анализ и обсуждение.
    -   Сопоставление эффективности графовых методов на трёх задачах.
    -   Выявление общих закономерностей (например, важность анализа топологии для всех трёх направлений).
    -   Ограничения: чувствительность к шуму, масштабируемость, зависимость от качества разметки.
-   Практические рекомендации.
    -   Для платформ (модерация), правоохранительных органов (приоритизация узлов в даркнете).
-   Ограничения и направления будущих исследований.
    -   Интеграция GNN с LLM, динамические графы, федеративное обучение, повышение объяснимости моделей.

## <span class="section-num">2</span> Датасеты {#датасеты}


### <span class="section-num">2.1</span> Датасеты для выявления ботов {#датасеты-для-выявления-ботов}


#### <span class="section-num">2.1.1</span> MGTAB {#mgtab}

-   Multi-Relational Graph-Based Twitter Account Detection Benchmark
-   Репозиторий: <https://github.com/GraphDetec/MGTAB>
-   Первый графовый бенчмарк, одновременно аннотирующий ботов и позиции пользователей (stance).
-   Содержит более 1.55 млн пользователей, 130 млн твитов и 10 199 экспертно размеченных аккаунтов.
-   Включает 7 типов связей между пользователями.


#### <span class="section-num">2.1.2</span> TwiBot-22 {#twibot-22}

-   Репозиторий: <https://twibot22.github.io/>
-   Крупнейший на сегодняшний день графовый бенчмарк для обнаружения ботов в Twitter.
-   Предоставляет разнообразные сущности и связи в социальном графе, а также включает перереализацию 35 базовых моделей для сравнения.

-   Репозиторий: <https://github.com/KaiDMML/FakeNewsNet>
-   Многомерный датасет для обнаружения фейковых новостей, включающий текстовые и визуальные признаки, а также социальный контекст (новостные статьи, твиты, пользовательские взаимодействия).
-   Содержит подмножества PolitiFact и BuzzFeed.

## <span class="section-num">3</span> Возможные программные комплексы {#возможные-программные-комплексы}


### <span class="section-num">3.1</span> Комплекс для выявления ботов {#комплекс-для-выявления-ботов}

-   Назначение:
    -   Исследовательский стенд и веб-приложение для классификации аккаунтов на основе мультиреляционного графа связей.

-   Ключевые функции:
    -   Построение динамических эго-графов пользователя с несколькими типами рёбер (follower, mention, reply, retweet, co-hashtag).
    -   Извлечение признаков профиля и текстовых эмбеддингов (например, LaBSE) для каждого узла.
    -   Обучение и сравнение нескольких GNN-архитектур: GCN, GAT, GraphSAGE, Relational GCN.
    -   Интерактивный веб-интерфейс, где пользователь вводит имя аккаунта и получает оценку вероятности «бот» с визуализацией его графа связей.

-   Ориентиры для реализации:
    -   MGTAB-Live
        -   Фреймворк, который использует двухслойный Relational GCN над семью типами рёбер и достигает 88,23% accuracy на бенчмарке MGTAB.
        -   Его архитектура (rate-limit-resilient scraper + Server-Sent Events + React frontend) может служить образцом для собственного прототипа.
    -   LGB (Language model + GNN)
        -   Гибридный подход, полезный для слабо связанных узлов (isolated nodes), которые чисто графовые методы пропускают.
        -   LGB доступен онлайн, что позволяет воспроизвести baseline и сравнить с ним свою модель.

-   Стек:
    -   PyTorch Geometric, DGL, FastAPI/Streamlit для демо, NetworkX для визуализации.

-   Что защищается как программный комплекс:
    -   Воспроизводимый пайплайн сырые данные → граф → обучение → метрики → веб-демо с возможностью замены датасета (MGTAB, TwiBot-22).


### <span class="section-num">3.2</span> Комплекс для обнаружения дезинформации {#комплекс-для-обнаружения-дезинформации}

-   Назначение:
    -   Платформа для анализа графа распространения новости и выявления фейков по структурным и временным паттернам.

-   Ключевые функции:
    -   Сбор каскада распространения (репосты, ответы, цитирования) с временными метками.
    -   Построение динамического графа распространения с возможностью срезов по времени (для задачи раннего обнаружения).
    -   Гибридная модель: текстовый энкодер (BERT/RoBERTa) + графовый модуль (GAT или Graph Transformer) для классификации каскада как «фейк / не фейк».
    -   Визуализация каскада с подсветкой «подозрительных» подграфов (например, кластеров низкодостоверных пользователей).
    -   Модуль «раннего предупреждения»: оценка вероятности фейка на ранних стадиях (первые N часов / первые K репостов).

-   Ориентиры для реализации:
    -   Dual-stream Graph-Augmented Transformer (BERT + GAT)
    -   CoST (Comprehensive Structural and Temporal Learning)
        -   Подход, который явно моделирует и структуру, и временную эволюцию каскада, что усиливает задачу раннего обнаружения.
    -   MAPLE (Multi-Graph Neural Network Attention Fusion)
    -   SCAN-NEWS
        -   Пример готовой платформы с графическим интерфейсом для проверки достоверности информации и визуализации графа диффузии.
        -   Полезен как референс по пользовательскому опыту и структуре модулей.

-   Стек:
    -   PyTorch, HuggingFace Transformers, PyG/DGL, Plotly/Dash для интерактивной визуализации каскада.

-   Что защищается:
    -   Программный комплекс с воспроизводимым экспериментом на PHEME (кросс-валидация по событиям) и демонстрацией работы модуля раннего предупреждения.


### <span class="section-num">3.3</span> Комплекс для анализа Darknet {#комплекс-для-анализа-darknet}

-   Назначение:
    -   Инструмент для построения графа скрытых сервисов Tor/I2P, выявления ключевых узлов и сообществ.

-   Ключевые функции:
    -   Краулер для сбора `.onion`, `.i2p` адресов (с учётом этических и правовых ограничений --- только публично доступные индексы и seed-узлы).
    -   Построение мультиграфа: узлы --- сервисы, рёбра --- гиперссылки, общие технологии, упоминания в форумах.
    -   Вычисление центральностей (in-degree, betweenness, PageRank) и выделение топ-узлов.
    -   Поиск сообществ алгоритмом Leiden, Louvain с последующей интерпретацией кластеров (например, «хакерские форумы», «криптомаркеты», «утечки данных»).
-   Интерактивная визуализация графа с возможностью фильтрации по типу связи и языку.

-   Ориентиры для реализации:
    -   VoidAccess
        -   OSINT-инструмент, который строит co-occurrence графы, сообщества и инфраструктурные кластеры из данных Tor-индексов, paste-сайтов и threat-фидов.
        -   Его пайплайн (сбор → обогащение → построение графа → экспорт в STIX/MISP) можно адаптировать под исследовательские задачи.
    -   Unveiling the mysteries of the dark web
        -   Исследование, в котором предложен one-size-fits-all граф с несколькими типами рёбер и узлов, поддерживающий анализ на уровне страниц и сайтов, а также анализ границ между даркнетом и surface web.
        -   Это готовый концептуальный каркас для вашего графа.
    -   Датасет Interconnection between darknets.

-   Стек:
    -   Python (Scrapy + stem для Tor), NetworkX/igraph, leidenalg, Gephi или Dash для визуализации.

-   Что защищается:
    -   Программный комплекс краулер → граф → метрики центральности → поиск сообществ → интерактивная карта с воспроизводимым анализом на публичном датасете.


### <span class="section-num">3.4</span> Общая библиотека для графового анализа соцсетей {#общая-библиотека-для-графового-анализа-соцсетей}

-   Унифицированная библиотека, которая поддерживает все сценарии через единый API:
    -   загрузчики датасетов (MGTAB, TwiBot-22, PHEME, Darknet Interconnection);
    -   конструкторы графов (гетерогенные, мультиреляционные, динамические);
    -   обёртки над GNN-моделями (GCN, GAT, GraphSAGE, R-GCN, Graph Transformer);
    -   стандартизированные метрики оценки (F1, AUC-ROC, а также graph-specific: homophily, modularity);
    -   модуль визуализации (экспорт в интерактивный HTML или интеграция с Dash).

-   Ориентиры:
    -   Spektral (для TensorFlow/Keras) и PyTorch Geometric
        -   Базовые библиотеки, на которые можно опереться, не изобретая слои GNN с нуля.
    -   EasyGraph
        -   Лёгкая библиотека для графового анализа, включающая модули EasyGNN.
        -   Удобно для быстрого прототипирования.

-   Что защищается:
    -   Библиотека с документацией, примерами использования для каждой из задач и сравнительными бенчмарками.
